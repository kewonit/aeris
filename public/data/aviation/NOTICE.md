# Aviation Data Sources

Aeris builds these files from open or public data. The generated files contain aircraft and airport facts only.

## Mictronics Aircraft Database

The aircraft database comes from the [Mictronics aircraft database](https://github.com/Mictronics/aircraft-database).

The source database uses the [Open Data Commons Attribution License](https://github.com/Mictronics/aircraft-database/blob/main/LICENSE).

Contains information from the Mictronics Aircraft Database. The database is available under the Open Data Commons Attribution License.

License: Open Data Commons Attribution License.

## FAA Aircraft Registry

US aircraft registration and model data comes from the [FAA releasable aircraft database](https://www.faa.gov/licenses_certificates/aircraft_certification/aircraft_registry/releasable_aircraft_download).

Aeris does not copy owner names, addresses, or other personal fields from the FAA files.

Source: Federal Aviation Administration aircraft registry.

License: United States government public data.

## OurAirports

Airport locations come from [OurAirports](https://ourairports.com/data/).

OurAirports releases its files into the public domain. The source provides the data without a warranty.

Source: OurAirports.

License: Public domain.
